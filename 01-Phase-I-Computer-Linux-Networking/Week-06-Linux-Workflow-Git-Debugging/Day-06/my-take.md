## 🧠 Core Mental Model

Shell alias and Shell functions are two ways to create shortcuts for commands in the shell. An alias is a simple way to create a shortcut for a command, while a function is a more powerful way to create a shortcut that can take arguments and perform more complex tasks.

Tmux is a terminal multiplexer that allows you to create multiple terminal sessions within a single terminal window. It allows you to split the terminal window into multiple panes, each running its own shell session. You can also detach from a tmux session and reattach later, allowing you to keep your work running in the background.
